# Project Bootstrapper — OPEN SOURCE

Heavily OSS (it's a commodity → openness is the whole value). D-007.

**Open (Apache/MIT):** the CLI, the built-in templates, the agent-context-file generators (CLAUDE.md/AGENTS.md/mcp.json/llms.txt scaffolds), the template engine. Maximize adoption + brand + community templates.

**Proprietary:** org custom templates + golden-path enforcement + private registry + ContextOS integration (the team/enterprise standardization layer).

**Rationale:** the templates/CLI are commodity → give them away for adoption, brand, and funnel into ContextOS. Monetize only **org standardization + governance** (a small, real B2B slice) — mostly via #1. Community contributes templates (great on-ramp). **Fork risk:** irrelevant — this is meant to be free; the value capture is ContextOS + saved internal time.
